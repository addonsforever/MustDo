# Bundled libraries

Must Do ships these libraries in `MustDo/Libs/`:

- **LibStub** — public domain.
- **CallbackHandler-1.0** — part of [Ace3](https://www.wowace.com/projects/ace3), BSD-style license.
- **HereBeDragons 2.0** (HereBeDragons-2.0, HereBeDragons-Pins-2.0) by Hendrik Leppkes (Nevcairiel) — [BSD license](https://github.com/Nevcairiel/HereBeDragons). This is [Questie](https://github.com/Questie/Questie)'s modified copy (`HereBeDragonsQuestie-2.0`), which handles Forever's Classic map data. Must Do changes one line so it works without Questie installed.
